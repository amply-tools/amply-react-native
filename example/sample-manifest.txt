# Amply sample apps — required control inventory
#
# CANONICAL COPY. The verbatim duplicate lives at
#   react-native-sdk/example/sample-manifest.txt
# because the two repos are separate gits and the RN package is published/mirrored
# publicly, so it cannot depend on a sibling checkout existing. Both copies must stay
# byte-identical: each repo's scripts/check-sample-parity.sh locates the other copy when
# the sibling repo is present and FAILS on any difference. Edit this file, then copy it
# across, in the same wave.
#
# One row per control that every sample must carry. The `id` is the exact string the
# sample tags its real widget with, in the platform's standard testing attribute:
#
#   iOS (UIKit)      view.accessibilityIdentifier = "amply.events.track"
#   Android (Compose) Modifier.testTag("amply.events.track")
#   React Native     testID="amply.events.track"
#
# The id literal must sit on the SAME LINE as the attribute — no indirection through a
# constants map for these ids. That co-location is what the checker can actually verify.
#
# Two machine-readable markers may start the note field:
#   prefix:    the id is a prefix; real ids are `<id>.<something>` and the checker
#              matches `"<id>.` rather than `"<id>"`.
#   launcharg: not a UI control — the id is a launch key name that must appear literally
#              in the sample's source (SAMPLE_APP_SPEC.md §7). No attribute is required.
# Every other row is an exact id: the checker matches `"<id>"`, quote to quote.
#
# Columns: x = required on that platform · - = not applicable, reason in the note.
# The prose that defines what each control DOES is samples/SAMPLE_APP_SPEC.md.
#
# revision: 5

# --- Shared strings ------------------------------------------------------------
# Wordings the spec requires all three platforms to render identically. Control ids
# are checked above; the SENTENCES a reader actually sees were not checked by
# anything, and the difference matters: the amber cleared-credentials notice was
# written into RN from the spec table while the native constants did not yet exist,
# and the byte-for-byte match had to be confirmed by hand. Confirmed by hand means
# unconfirmed the next time someone edits one of the three.
#
# Format: string: <label> | <swift symbol> | <kotlin symbol> | <ts symbol>
#
# string: refusal-cause | refusalCause | REFUSAL_CAUSE | REFUSAL_CAUSE
# string: cleared | clearedWhileRunningNotice | CLEARED_WHILE_RUNNING_NOTICE | RUNNING_ON_CLEARED_CREDENTIALS
